About Me

Hi, I'm Syeda Alishba — a final-year Software Engineering student at the University of Karachi (UBIT), focused on Data Science, AI, and backend development. I'm passionate about building systems that are both intelligent and production-ready.

I've built a Multi-User RAG AI Assistant using locally hosted LLMs with Ollama and LangChain, featuring document chunking, vector retrieval, context injection, and conversational memory. On the web side, I've developed full-stack platforms using Django REST Framework, FastAPI, and the MERN stack.

Beyond backend work, I've explored Exploratory Data Analysis and trained Convolutional Neural Networks for real-world classification tasks. I enjoy working across the full spectrum from clean API architecture to responsive frontends.
